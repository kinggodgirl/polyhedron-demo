# 다면체 1차시 수업 웹앱 (polyhedron-demo)

중학교 1학년 「다면체」 본 차시에서 교사가 PC·전자칠판에 띄워 PPT 대신 쓰는 수업 웹앱입니다. 파일 하나(index.html)라서 인터넷 없이 내려받아 열어도 됩니다(글꼴만 기본 글꼴로 바뀜). 방과후용 학생 앱은 [polyhedron-lab](https://github.com/kinggodgirl/polyhedron-lab)에 있습니다.

## 장면 (← → 키, 발표용 리모컨 PageUp/PageDown으로 넘기기)
학습지 「Ⅶ-01. 다면체 1차시」 순서와 맞춰 두었고, 장면마다 오른쪽 위에 **학습지 항목**(노란 표)이 보입니다. 위쪽 동그라미 번호는 지금 단원의 장면만 보여 줍니다.

1. **도입**
   1. 표지 — Ⅶ. 입체도형의 성질 / 01. 다면체 1차시 / 교과서 P.211~212
   2. 건축물 퀴즈 — 부르즈 할리파 · 메르데카 118 · 상하이 타워 층수 맞히기 → "입체도형을 파악하려면 층을 알아야 한다!"
   3. 학습목표
2. **다면체의 뜻** (주요개념 1)
   4. 다면체일까, 아닐까? — 카드 분류
   5. 다면체의 뜻 만들기 — 빈칸 추론
   6. 학습지 O/X 확인 — 학습지의 4개 도형(오각뿔, 원기둥, 사각뿔대, 평면 사각형)
3. **다면체의 이름** (주요개념 2 · 연습하기)
   7. 면의 개수로 이름 짓기
   8. 각기둥과 각뿔로 나눠 보기
   9. 각뿔을 잘라 각뿔대 만들기
   10. 각기둥 · 각뿔대 · 각뿔 — 윗면 크기 슬라이더
   11. 연습하기 — 학습지의 4개 도형(오각뿔, 사각뿔대, 삼각기둥, 팔각뿔대)의 이름 2가지. ①②가 둘 다 육면체임을 짚어 줌
4. **구성 요소의 개수** (생각익히기)
   12. 면 · 모서리 · 꼭짓점
   13. 층마다 세기 — 1층 → 2층(각뿔이면 점 하나) → 층 사이. 학습지 도형 바로 불러오기, 윗층 크기 슬라이더
   14. 다면체 분석하기 — 학습지 표 그대로(삼각뿔대, 육각뿔, 오각기둥). 개수 칸을 열면 층별 식(예: 3 + 3 + 0)도 함께. 육각뿔 · 오각기둥이 둘 다 칠면체임을 짚어 줌
   15. 개수 세고 규칙 찾기 — n각기둥 등의 규칙
5. **마무리 · 도전**
   16. 거꾸로 생각하기 — 학습지 역문제(면이 8개인 각뿔대, b − a)를 층 격자로 단계별 풀이 + 더 해 보기(모서리 12개인 다면체 찾기)
   17. 직접 그려봅시다 — 1층 → 2층 → 층 사이 순서로 겨냥도 그리기(흑백, 보이지 않는 선은 점선)
   18. 도전: 왜 이면체, 삼면체는 없을까? — 면 2개 · 3개 · 4개를 한 점에 모아 보기 + 층으로 설명하기
   19. 도전: 팔면체도 층으로 — 점 · 사각형 · 점 3층으로 세기 (정다면체 차시로 가는 다리)

크게 보기 창에서는 O/X(또는 1·2·3) 키로 고르고 ← → 키로 도형을 넘깁니다.
무대 우측 하단의 **고정 축** 체크박스로 상하·좌우 2방향 회전을, **밑면 평행** 버튼으로 수평 정렬을 할 수 있습니다.
스페이스 키는 각 장면의 주 동작(공개, 세기, 다음 층 쌓기 등)을 실행합니다. 주소 끝에 `#s3`처럼 붙이면 그 장면에서 시작합니다.

## 3D 엔진 (시범)
머리 오른쪽의 **3D 엔진** 체크박스를 켜면 three.js(r187, `vendor/`)로 그립니다. 끄면 원래 2D 엔진으로 돌아갑니다(브라우저가 기억함).
- 거의 모든 장면에 적용됩니다: 도형 보기, 공 넣기 · 뒤집기, 층 쌓기, 직접 눌러 세기, 직접 그려봅시다.
- 2D로 그리는 곳: 각뿔 자르기(칼날), 각뿔대의 늘린 옆 모서리, 분류 카드의 작은 그림.
- 곡면(원기둥 · 원뿔 등)은 윤곽선과 밑면의 가려진 반쪽 점선까지 그립니다.
- 꼭짓점 점과 번호 동그라미는 위에 겹친 2D 캔버스에 그립니다(투영이 같아 위치가 맞음). 누르기 판정도 그대로 씁니다.
- 겨냥도처럼 평행 투영 + 굵은 모서리 + 보이지 않는 모서리 점선으로 그립니다.
- three.js는 모듈로 불러오므로 **인터넷 주소(GitHub Pages)로 열 때만** 켜집니다. 파일을 내려받아 더블클릭으로 열면 2D 엔진만 됩니다.

## 공 넣기 · 뒤집기
뚜껑 없는 상자(4번 장면 8번 도형, 5번 장면)와 정육면체에 있습니다.
- 뚜껑 없는 상자: 공을 붓고 **뒤집기** → 공이 쏟아짐 (둘러싸여 있지 않음)
- 정육면체: **안에 공 넣기** → 뒤집어도 공이 그대로 (반투명으로 보여 줌)
