# 다면체 수업 시연 (polyhedron-demo)

중학교 1학년 「다면체」 본 차시에서 교사가 PC·전자칠판에 띄워 시연하는 웹앱입니다. 방과후용 학생 앱은 [polyhedron-lab](https://github.com/kinggodgirl/polyhedron-lab)에 있습니다.

## 장면 (← → 키, 발표용 리모컨 PageUp/PageDown으로 넘기기)
1. **다면체의 뜻**
   1. 다면체일까, 아닐까? — 카드를 눌러 크게 보고 "다면체다/아니다"로 나누기(고르면 다음 도형으로, 끌어서 옮기기도 가능) → 정답 공개
   2. 다면체의 뜻 만들기 — 빈칸(다각형인 면으로만 · 둘러싸인 · 입체도형)을 열면 걸러지는 도형이 나옴
2. **다면체의 이름**
   3. 면의 개수로 이름 짓기 — 면을 직접 눌러 불을 켜며 세고 "○면체"로 (자동 세기도 있음)
   4. 각기둥과 각뿔로 나눠 보기 — 초등에서 배운 각기둥·각뿔로 나누고, 남은 도형(각뿔대 등)을 소개
   5. 각뿔을 잘라 각뿔대 만들기 — 평행하게/비스듬히 자르기
   6. 각기둥 · 각뿔대 · 각뿔 — 윗면 크기 슬라이더, 밑면 모양으로 이름 짓기
3. **구성 요소의 개수**
   7. 면 · 모서리 · 꼭짓점 — 고른 것을 도형에서 직접 눌러 세기 (자동 세기도 있음)
   8. 개수 세고 규칙 찾기 — 직접 세거나 자동으로 세면 표가 채워짐, 칸을 눌러 공개, 마지막 줄에서 규칙(2n, 3n, n+2 …)

크게 보기 창에서는 O/X(또는 1·2·3) 키로 고르고 ← → 키로 도형을 넘깁니다.
스페이스 키는 각 장면의 주 동작(공개, 세기 등)을 실행합니다. 주소 끝에 `#s3`처럼 붙이면 그 장면에서 시작합니다.
