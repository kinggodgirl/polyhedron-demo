# 다면체 수업 시연 (polyhedron-demo)

중학교 1학년 「다면체」 본 차시에서 교사가 PC·전자칠판에 띄워 시연하는 웹앱입니다. 방과후용 학생 앱은 [polyhedron-lab](https://github.com/kinggodgirl/polyhedron-lab)에 있습니다.

## 장면 (← → 키, 발표용 리모컨 PageUp/PageDown으로 넘기기)
1. **다면체의 뜻**
   1. 다면체일까, 아닐까? — 카드를 눌러 크게 보고 "다면체다/아니다/보류"로 나누기(고르면 다음 도형으로, 끌어서 옮기기도 가능) → 정답 및 까닭 공개
   2. 다면체의 뜻 만들기 — 다면체가 아닌 도형(원기둥, 뚜껑 없는 상자, 평면 오각형)을 먼저 보며 빈칸(다각형인 면으로만 · 둘러싸인 · 입체도형)을 추론해 열기
2. **다면체의 이름**
   3. 면의 개수로 이름 짓기 — 오른쪽 3D 모양 버튼을 고르고 면을 직접 눌러 불을 켜며 세기 → 다 세면 "○면체"와 도형 이름 공개 (자동 세기도 있음)
   4. 각기둥과 각뿔로 나눠 보기 — 초등에서 배운 각기둥·각뿔로 나누고, 남은 도형(각뿔대 등)을 소개
   5. 각뿔을 잘라 각뿔대 만들기 — 평행하게/비스듬히 자르기
   6. 각기둥 · 각뿔대 · 각뿔 — 윗면 크기 슬라이더, 밑면 모양으로 이름 짓기
3. **구성 요소의 개수**
   7. 면 · 모서리 · 꼭짓점 — 고른 것을 도형에서 직접 눌러 세기 (자동 세기도 있음)
   8. 층마다 세기 — 1층(아래 다각형) → 2층(위 다각형, 각뿔이면 점 하나) → 층 사이(잇는 모서리·옆면) 순서로 쌓기. 표(꼭짓점·모서리·면 × 1층·2층·층 사이)는 칸을 눌러야 열림. 윗층 크기 슬라이더를 0까지 줄이면 2층이 점 하나가 되어 각뿔이 됨
   9. 개수 세고 규칙 찾기 — 직접 세거나 자동으로 세면 표가 채워짐, 칸을 눌러 공개(전체 공개/가리기 지원), 마지막 줄에서 규칙(2n, 3n, n+2 …)

크게 보기 창에서는 O/X(또는 1·2·3) 키로 고르고 ← → 키로 도형을 넘깁니다.
무대 우측 하단의 **고정 축** 체크박스로 상하·좌우 2방향 회전을, **밑면 평행** 버튼으로 수평 정렬을 할 수 있습니다.
스페이스 키는 각 장면의 주 동작(공개, 세기, 다음 층 쌓기 등)을 실행합니다. 주소 끝에 `#s3`처럼 붙이면 그 장면에서 시작합니다.
